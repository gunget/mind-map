# 아이디어 블럭 커넥터 (Idea Block Connector)

**현재 버전:** v82  
**기술 스택:** Vanilla JS, HTML5 Canvas API, File System Access API, IndexedDB, OS Clipboard API  
**작동 환경:** 로컬 파일 환경 (`file://`) 기반의 단일 HTML 파일 애플리케이션  

---

## 📌 프로젝트 소개
아이디어를 시각적으로 맵핑하고 연결하는 노드 기반의 다이어그램/마인드맵 도구입니다.  
서버나 외부 라이브러리 없이 순수 브라우저 API만을 활용하여 단일 HTML 파일 내에서 여러 시트(페이지)를 독립적이고 안전하게 통합 관리합니다.

### 주요 기능
- **프레젠테이션(PT) 모드 (v82)**: 좌상단 📽️ 버튼(`F5`)으로 몰입형 발표 모드 진입, 키보드 좌우(`←`/`→`) 화살표 흐름 순차 탐색, 자식 블록 갈래 전환(`↑`/`↓`), 세로 긴 블럭 화면 90% 맞춤 스마트 줌, 체크포인트 핀(좌상단 꽂힘 및 복귀 후 자동 회수), 우상단 고시인성 다크 글래스 HUD(자유 드래그 이동 가능)
- **스마트 화살표 & 서식 메뉴 (v81)**: 4가지 선 종류(실선, 점선, 긴 파선, 두 줄선), 꺾인선 화살표 헤드, 투명도 슬라이더(0~100%), 베지어 곡선 자동 굴곡 및 단방향/양방향
- **읽기 모드 블럭 선택 & 복사 (v81)**: 새창으로 열린 읽기 모드 시트에서도 블럭을 선택하여 작업 창으로 복사(`Ctrl+C` / `Ctrl+V`)
- **블럭(노드) 생성 & 편집**: 사각형, 밑줄 스타일, 해시태그 스타일, 투명 텍스트, 이미지 노드, 숫자 마커(1~50), 영역 박스
- **리치 텍스트 서식**: 볼드(`**`), 기울임(`*`), 밑줄(`__`), 7가지 색상(`[c:#color]`), 정렬, 선택영역 색상 단축키(`Ctrl+Q` 후 숫자 `1~7`)
- **멀티 시트(페이지) 초경량 관리**: 단일 HTML 파일 내에 여러 시트를 순수 데이터(JSON)로 캡슐화하여 보관, 교체, 최신 엔진 동적 주입 새 창 열기 (용량 90% 절감, 새창 전용 60% 투명도 `[읽기 모드]` 표시)
- **고성능 렌더링 엔진 (v81 최적화)**: 텍스트 레이아웃 캐싱, 뷰포트 컬링, 격자 간격 최적화(200px), 스마트 더티 플래그 반응형 루프로 대규모 다이어그램에서도 60fps 유지
- **로컬 영속성**: File System Access API 및 IndexedDB를 통한 실시간 덮어쓰기 저장 및 최근 작업 불러오기
- **크로스 탭 복사/붙여넣기**: OS 클립보드를 통한 탭 간 블록 복사 지원
